# 시뮬

헤드리스로 런을 반복해 밸런스 수치의 근거를 잡는 하네스다. 코드는 `scripts/sim/`에 있고 진입점은 `scripts/main.gd`다.

## 실행

```sh
godot4 --headless res://scenes/Main.tscn -- <모드>
```

환경변수는 명령 앞에 붙인다.

```sh
SIM_MAXDAY=4 SIM_N=500 SIM_CURVE=5,2.5,3 godot4 --headless res://scenes/Main.tscn -- --simtier
```

실행이 겹치면 이전 godot 프로세스가 CPU를 잡고 있어 느려진다. `pkill -f Main.tscn`로 정리한 뒤 돌린다.

## 모드

| 모드 | 내용 | 기본 판수 |
|---|---|---|
| `--sim` | 생존 시뮬. 상점을 켜고 빈 상태에서 스스로 슬롯과 버프를 사며 12주까지 진행한다. 승률, 최종 돈, 서빙, 놓친 손님, 생존 주 분포를 집계한다 | 200 |
| `--simbuffs` | 버프 하나씩 단독으로 넣고 기준 대비 점수, 승률, 돈 변화를 잰다. 상점을 꺼서 순효과만 본다 | 40 |
| `--simtier` | 조건부 서빙 보너스 53~55번 배수 곡선 탐색. 세 카드에 같은 배수를 스윕하거나 카드별 곡선을 검증한다 | 200 |
| `--simsyn` | 버프 두 장 조합의 시너지를 잰다. 조합 변화량에서 단독 변화량의 합을 뺀 값이다 | 40 |
| `--simstate` | 서빙 시점의 평균 보드 상태를 잰다. 버프 수, 찬 슬롯, 빈 슬롯, 완성품, 주문서, 재료 수다 | 200 |
| `--simmenu` | 메뉴 하나만 팔게 강제하고 메뉴별 하루 점수, 재료당 점수, 조리초당 점수를 비교한다 | 300 |
| `--simshard <판수> <시작> <개수>` | `--simbuffs`를 버프 구간별로 나눠 병렬 실행한다. 끝에 `surv`를 붙이면 생존 주 기준으로 잰다 | 인자 |
| `--simcount` | 버프 카드 수만 출력한다 | 없음 |
| `--replay` | 실플레이 로그의 주별 버프 구성을 그대로 재현해 서빙과 점수를 로그와 비교한다 | 30 |

## 환경변수

### 플레이어 모델

시뮬 플레이어의 손 속도와 실수를 정한다. `--sim`과 `--simstate`는 값이 없으면 실측에 맞춘 기본값을 쓴다.

| 변수 | 내용 | 기본값 |
|---|---|---|
| `SIM_HANDLE` | 서빙, 조리, 주문 접수, 재료 놓기마다 손이 묶이는 시간 배수. 0이면 즉시 처리 | `--sim` 0.65, 그 외 0 |
| `SIM_MISS` | 손님이 도착할 때 놓칠 확률 | `--sim` 0.03, 그 외 0 |
| `SIM_FUMBLE` | 매 틱 행동을 건너뛸 확률 | 0 |
| `SIM_TRIP` | 창고 퇴장 시간 기본값을 이 초로 바꾼다 | Config 값 |

### 진행 범위

| 변수 | 내용 | 기본값 |
|---|---|---|
| `SIM_N` | 판수 | 모드별 |
| `SIM_MAXDAY` | 이 주까지만 진행하는 고정 지평선 | 12 |
| `SIM_NOFAIL` | 주 목표에 못 미쳐도 계속 진행한다. 점수 누적만 볼 때 쓰고 후반 주에서 무한 루프에 주의한다 | 꺼짐 |
| `SIM_TRACE` | 이 수보다 작은 시드의 판은 주별 추적을 출력한다 | 꺼짐 |
| `SIM_SHOP` | 시뮬할 가게 | 도넛 카페 |
| `SIM_BOSS` | 매주 이 계약 갱신 심사 제약을 강제한다 | 꺼짐 |
| `SIM_SLOTS` | 시작 슬롯 수를 덮어쓴다 | 기본 슬롯 |
| `SIM_PICK_RANK` | `--sim` 상점에서 버프 팩 후보 중 몇 번째로 좋은 카드를 고를지 | 2 |

### 모드별

| 변수 | 모드 | 내용 |
|---|---|---|
| `SIM_MULTS` | `--simtier` | 스윕할 배수 목록, 쉼표 구분. 기본 2, 3, 5, 9 |
| `SIM_CURVE` | `--simtier` | 53, 54, 55번에 각각 줄 배수, 쉼표 구분 |
| `SIM_CTX` | `--simbuffs` | 기준 상태에 미리 깔아둘 버프 id 목록 |
| `SIM_BUFF_ONLY` | `--simbuffs` | 이 버프 id만 잰다 |
| `SIM_STATE_IDS` | `--simstate` | 미리 깔아둘 버프 id 목록 |
| `SIM_SYN_IDS` | `--simsyn` | 조합할 후보 버프 id. 없으면 단독 상위 카드에서 고른다 |
| `SIM_SYN_K` | `--simsyn` | 자동으로 고를 후보 수. 기본 8 |
| `SIM_SYN_SURV` | `--simsyn` | 점수 대신 생존 주로 잰다 |
| `SIM_FULLSHOP` | `--simshard surv` | 슬롯만 사지 않고 버프 팩도 산다 |

## 측정 주의

상점을 끄고 무한 생존으로 돌리면 점수 카드의 승률은 항상 0%다. 승리 조건에 닿지 못해서다. 변별은 생존 주나 `SIM_MAXDAY` 고정 지평선의 누적 점수로 한다.

## 가게별 기준선

| 가게 | `--sim` 완주율 |
|---|---|
| 도넛 카페 | 약 30% |
| 버거집 | 40%, 목숨 꺼짐 |

## 시뮬 미지원 카드

해당 기능이 시뮬에 없어 효과를 잴 수 없는 카드다. `buff_defs.gd`에서 `blocked`로 표시하면 시뮬 풀에서 빠지고 게임에는 그대로 등장한다.

| 카드 | 막힌 이유 |
|---|---|
| 7, 8, 50 | 상점 관련, 시뮬은 주 사이 상점을 건너뜀 |
| 10 | 대기열 공개, 기계적 효과 없는 순수 정보 |
| 59, 60 | 자동 서빙과 자동 조리, 시뮬 플레이어가 이미 자동이라 효과 분리 측정이 애매 |
| 46 초기화 조건 | 재료 버리기가 시뮬에 없음, 누적 자체는 측정 가능 |
