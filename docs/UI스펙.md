표기 규칙은 아래와 같다. 아이콘은 `assets/art/ui`의 이름으로 적고, 텍스트는 최소화하고 아이콘으로 대신한다.

## 컴포넌트

| 컴포넌트 | 내용 |
|---|---|
| `*Card*` | 슬롯에 놓이는 카드 공통 틀, 재료/주문서/완성품 세 종류 |
| `*Slot*` | 카드가 놓이는 칸, 변형으로 도구석과 잠긴 칸 |
| `*TopBar*` | 상단 정보 바, 메인 게임과 상점이 공용 |
| `*Sheet*` | 하단에서 올라오는 시트, 맨 위 손잡이를 눌러 닫음, 창고/조리/보유 버프가 공용 |
| `*Modal*` | 딤 배경 위 중앙 패널, 마감 정산/주 통과/런 실패가 공용 |
| `*BigBanner*` | 화면 중앙에 잠깐 뜨는 큰 배너, 영업 시작과 마감에 사용 |
| `*BuffCard*` | 버프 카드, 이름과 설명으로 구성, 팩 개봉/보유 목록/도감이 공용 |
| `*Toast*` | 짧게 떴다 사라지는 알림 |

버튼 색은 역할로 정한다.

| 역할 | 색 |
|---|---|
| 진행 | MAIN |
| 보조 | SUB |
| 취소, 부차 기능 | COCOA_100 |
| 비활성 | COCOA_200 |

## 1. 타이틀

배경 그림 위에 제목과 버튼을 세로로 놓는다.

```
┌───────────────────────┐
│                [settings] │
│                       │
│      SLOT KITCHEN     │
│                       │
│        [ play ]       │
│        [ 도감 ]       │
│                       │
│              버전표기 │
└───────────────────────┘
```

| 요소 | 위치 | 동작 |
|---|---|---|
| 게임 제목 | 중앙 | - |
| `[play]` | 중앙 | 가게 선택으로 이동 |
| `[도감]` | 중앙 | 도감 열기 |
| `[settings]` | 우상단 | 설정 열기 |
| 빌드 버전 | 우하단 | 표기만 |

메모

- 목숨 해금 조건을 처음 달성하면 타이틀 전에 해금 안내가 나온다. 딤 위에 heart 아이콘과 문장 네 줄을 한 줄씩 탭으로 넘긴다.

## 2. 가게 선택

가게 카드를 세로로 나열하고 카드에는 가게 대표 아이콘만 둔다.

```
┌───────────────────────┐
│ [house]                  │
│       가게 선택       │
│   ┌───────────────┐   │
│   │    도넛 카페   │   │
│   └───────────────┘   │
│   ┌───────────────┐   │
│   │ 잠금 Coming Soon│  │
│   └───────────────┘   │
└───────────────────────┘
```

| 요소 | 내용 |
|---|---|
| 가게 카드 | 대표 아이콘만 표시 |
| 잠긴 가게 | 비활성 카드에 자물쇠와 Coming Soon |
| `[house]` | 좌상단, 타이틀로 복귀 |

## 3. 메인 게임

상단은 정보만, 인터랙션은 하단 엄지존에 둔다.

```
┌───────────────────────┐
│ [house]  목숨 | 별 {점수} | 돈 {n} │  TopBar 1행
│ {n}주차  해 [▓▓▓░░░] 달  │  TopBar 2행, 영업시간
├───────────────────────┤
│ 손님 큐  손님 손님 손님 손님 │  쪽지와 인내심 표시
├───────────────────────┤
│   ┌────┬────┬────┐   │
│   │재료│주문│도구│   │
│   ├────┼────┼────┤   │  Slot 그리드
│   │재료│ 빈 │재료│   │
│   ├────┼────┼────┤   │
│   │주문│재료│도구│   │
│   └────┴────┴────┘   │
├───────────────────────┤
│ [trash] [buffs]   [warehouse] │
└───────────────────────┘
```

| 영역 | 내용 |
|---|---|
| TopBar 1행 | `[house]`, 목숨, 별과 이번 달 점수, coin 아이콘과 돈 |
| TopBar 2행 | 주차 배지, 해에서 달로 차오르는 영업시간 바 |
| 손님 큐 | 손님 카드마다 쪽지와 인내심 게이지 |
| 도구석 | 조리 중이면 원형 타이머가 돈다 |
| 하단 왼쪽 | `[trash]`, `[buffs]` |
| 하단 오른쪽 | 큰 `[warehouse]` 손잡이 |

메모

- 목숨은 해금된 런에서만 보인다.
- 버프를 하나도 안 가졌으면 `[buffs]`가 비활성이다.
- `[house]`는 런을 중단하고 타이틀로 돌아간다.

## 4. 영업 시작 배너

주가 시작되면 `*BigBanner*`로 해 아이콘과 OPEN을 띄우고 아래에 월 진행 트랙을 붙인다.

| 요소 | 내용 |
|---|---|
| 월 진행 트랙 | 이번 달 네 주를 점으로 잇고 끝에 별, 지난 주와 이번 주는 진하게, 남은 주는 흐리게 |
| 트랙 아래 문구 | `{n}주 뒤 본사 감사`와 그 달 심사에 걸릴 제약의 아이콘과 이름 |

월말 심사 주에는 OPEN 배너 대신 심사일 배너가 뜬다. 딤 위에 계약 도장 boss_seal, `계약 갱신 심사`, 걸린 제약의 아이콘과 이름, 목표를 세로로 놓고 탭하면 영업을 시작한다.

메모

- 새 달로 넘어갈 때는 별도 전환 화면이 뜬다. 딤 위에 `{n}달차`와 깜빡이는 `손님 인내심 감소`를 띄우고 탭하면 닫힌다.

## 5. 창고 시트

`*Sheet*`에 재료 타일을 4열 그리드로 놓고 타일을 탭하면 꺼낸다.

```
├───────────────────────┤
│        ──손잡이──      │
│   밀가루 계란 설탕 초코  │
│   원두   우유  물       │
└───────────────────────┘
```

| 상태 | 표시 |
|---|---|
| 빈 슬롯 없음 | 타일 전체가 흐려지고 눌리지 않음 |
| 버프로 빠진 재료 | 그 타일만 흐려지고 눌리지 않음 |

---

## 6. 조리 시트

도구를 탭하면 열리고 메뉴마다 한 줄이다.

```
├───────────────────────┤
│        ──손잡이──      │
│ 메뉴 $  | 재료 재료 재료   별 {점수} │
│                       타이머 {초} │
│ 메뉴 $$ | 재료 재료        별 {점수} │
│                       타이머 {초} │
└───────────────────────┘
```

| 위치 | 내용 |
|---|---|
| 왼쪽 | 메뉴 아이콘 |
| 그다음 | SUCCESS 색 가격대 `$`에서 `$$$` |
| 가운데 | 필요 재료 아이콘 |
| 오른쪽 끝 | 서빙 점수와 조리 시간 |

| 상태 | 표시 |
|---|---|
| 필드에 없는 재료 | 흐리게 표시 |
| 재료가 모자란 줄 | 비활성 |

---

## 7. 보유 버프 시트

`*Sheet*`에 보유 버프를 세로 목록으로 놓고 메인 게임과 상점이 같은 시트를 쓴다.

| 요소 | 내용 |
|---|---|
| 우상단 | 보유 개수 `{n}/{상한}`, MAIN 색 |
| 각 줄 | 이름, 설명, `[판매]` |

## 8. 마감 정산

주 영업이 끝나면 `*Modal*`이 뜬다.

```
┌───────────────────────┐
│      {n}주차 마감      │
│ 메뉴 ×{개수}  별 {점수}  +{보너스} │
│ 메뉴 ×{개수}  별 {점수}        │
│ 이탈율          {n}%   │
│ 마감 보너스  돈 {n}   │
│                       │
│      [ 실적 확인 ]     │
└───────────────────────┘
```

| 요소 | 내용 |
|---|---|
| 판매 줄 | 메뉴별 판매 수와 점수 합, 버프로 더 얻은 점수는 MAIN 색 `+{n}` |
| 이탈율, 마감 보너스 | 해당 값이 있을 때만 줄 생성 |
| `[실적 확인]` | 목표 통과 여부 판정, 통과하면 주 통과 창으로 이동 |

미달 시 아래에 두 버튼이 펼쳐진다.

| 버튼 | 색 | 동작 |
|---|---|---|
| `[{n} 소모]` | DANGER | 돈을 내고 통과, 돈이 모자라면 비활성 |
| `[파산 신청]` | COCOA_100 | 런 실패로 이동 |

## 9. 주 통과

```
┌───────────────────────┐
│     Week {n} Clear!   │
│  주간 보상  돈 {n}   │
│                       │
│      [ 상점으로 ]      │
└───────────────────────┘
```

메모

- 배너가 SUCCESS 색으로 튀어나오고 주간 보상 돈이 상단바로 날아간다.
- 월말 주였다면 `[상점으로]`를 누른 뒤 점수 리셋 연출과 새 달 전환 화면을 거쳐 상점으로 간다.

## 10. 런 실패

`*Modal*`에 DANGER 색 `Run Failed`와 `[house]` 버튼 하나만 있다. 누르면 페이드 후 타이틀로 간다. 파산 신청과 목숨 소진 모두 이 창으로 온다.

---

## 11. 상점

전체 화면이고 상단에 `*TopBar*`를 그대로 쓴다. 점수 자리에 `{현재 점수}/{다음 목표}`을 보여 주고, 다음 주가 월말이면 이 숫자가 DANGER 색이다.

```
┌───────────────────────┐
│ [house] 목숨 | 별 {점수}/{목표} | 돈 {n} │
│ {n}주차                │
├───────────────────────┤
│ ┌───────────────────┐ │
│ │ 슬롯 확장   돈 {가격} [구매] │ │
│ └───────────────────┘ │
│ ┌───────────────────┐ │
│ │ 버프 팩     돈 {가격} [구매] │ │
│ └───────────────────┘ │
│ ┌───────────────────┐ │
│ │ 버프 팩     돈 {가격} [구매] │ │
│ └───────────────────┘ │
├───────────────────────┤
│           [buffs] [ >> ] │
└───────────────────────┘
```

| 요소 | 내용 |
|---|---|
| 상품 | 세 줄, 슬롯 확장권 줄이 먼저 오고 나머지는 버프 팩 |
| 구매 후 | 그 줄은 품절로 변경 |
| `[buffs]` | 오른쪽 아래, 보유 버프 시트 열기 |
| `[>>]` | 겹화살표, 다음 주 영업 시작 |

## 12. 버프 팩 개봉

딤 위에 `3개 중 1개 선택`과 `*BuffCard*` 세 장을 가로로 놓고 카드마다 `[선택]`이 있다.

```
┌───────────────────────┐
│     3개 중 1개 선택    │
│ ┌─────┐ ┌─────┐ ┌─────┐ │
│ │ 이름 │ │ 이름 │ │ 이름 │ │
│ │ 설명 │ │ 설명 │ │ 설명 │ │
│ │[선택]│ │[선택]│ │[선택]│ │
│ └─────┘ └─────┘ └─────┘ │
│        [ 패스 ]        │
│     [리롤 {n}]    │
└───────────────────────┘
```

| 버튼 | 색 | 동작 |
|---|---|---|
| `[선택]` | - | 해당 카드 획득 |
| `[패스]` | - | 아무것도 받지 않고 닫기 |
| `[리롤]` | SUB | 누를 때마다 값이 두 배, 돈이 모자라면 흐리게 비활성 |

메모

- 보유 버프가 가득 차 있으면 위에 `버프칸 가득` 경고가 뜨고, 고르려 하면 카드가 흔들린다.

## 효과음과 진동

효과음은 `scripts/audio.gd`의 `SFX`에 모여 있고 `Audio.play("id")`로 재생한다. 개별 볼륨 보정은 `SFX_GAIN_DB`, 배경음 볼륨은 `BGM_VOLUME_DB`에서 한다. 설정의 배경음, 효과음, 진동 토글이 각각 재생을 켜고 끈다.

진동은 임팩트 순간에만 준다. `Audio.vibrate(ms)`는 모바일에서만 동작하고 데스크톱에서는 아무 일도 하지 않는다. 사건이 클수록 길게 준다.

| 사건 | 길이 |
|---|---|
| 슬롯에 카드 안착 | 10ms |
| 마감 카운트다운 | 15ms |
| 서빙, 조리 확정 | 20ms |
| 막힌 동작, 주 통과, 버프 팩 개봉 | 30ms |
| 손님 이탈, 마감 | 40ms |
| 목숨 감소 | 55ms 두 번 |
| 런 실패 | 60ms |
