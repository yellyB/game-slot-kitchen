# 버프 카드

버프 카드는 그룹별로 묶어 배치한다. 이름과 효과는 게임 안 문구와 같다.

## 표기 규칙

- 번호는 문서 관리용 카드 번호이고 `data/buff_defs.gd`의 `card` 필드로 slug와 매핑한다. 28, 29, 30번은 비어 있다.
- 효과 열의 `{...}`는 강화 업그레이드로 바뀌는 수치다. 조건, 트리거, 티어 지정, 구조 카운트는 고정이라 표기하지 않는다.
- 판매 수입은 점수 또는 추가 점수다. 돈으로 지급하는 카드는 돈과 마감 보너스 그룹의 63, 76, 77, 78번과 목숨 그룹의 73번뿐이다.
- 가격대 표기는 `$` 일반, `$$` 고급, `$$$` 프리미엄이다.
