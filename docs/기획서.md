# 슬롯 키친 기획서

좁은 슬롯 판에서 주문, 재료, 조리가 같은 자리를 두고 싸우는 카드 기반 실시간 요리 타이쿤. 손님 주문을 받고 창고에서 재료를 꺼내 조리해 서빙하며 매주 목표 점수를 넘겨 버티는 정체 관리 게임이다.

## 용어

| 용어 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 주 | 영업 한 번이자 시간 단위, 게임에서는 n주차로 표시 | 하루, 일, 라운드, 세션 |
| 달 | 4주, 게임에서는 n달차로 표시 | |
| 런 | 3달 12주로 이뤄진 한 판, 성공하면 런 완료 | |
| 런 실패 | 런이 끝나는 실패, 게임에서는 Run Failed. 원인은 파산 신청과 목숨 소진 두 가지 | 런오버, 폐업 |
| 파산 신청 | 주 목표 미달에 돈도 부족할 때 런 실패를 고르는 버튼 | |
| 점수 | 서빙으로 얻는 값, 마감 창에서는 실적이라고 표시 | |
| 주 목표, 월 목표 | 매주 마감에 넘겨야 하는 누적 점수, 4주차의 주 목표가 월 목표 | 관문, 게이트, 가게세, 월세 |
| 돈 | 상점 화폐, 단위는 원, 화면에서는 코인 아이콘으로 표시 | 코인, 현금 |
| 목숨 | 손님 이탈마다 줄고 0이면 런 실패, 화면에서는 하트 아이콘 | 하트, 라이프 |
| 계약 갱신 심사 | 월말 4주차에 제약 하나를 거는 이벤트, 예고 문구는 본사 감사 | 보스, 보스데이 |
| 슬롯 | 판의 칸 하나 | |
| 도구 | 조리하는 기구, 판의 도구석에 놓임 | 조리 도구, 화구, 오븐 |
| 주문서 | 주문을 받으면 슬롯에 들어오는 카드 | 주문 카드, 쪽지, 티켓 |
| 완성품 | 조리가 끝난 음식 카드 | 요리, 디시 |
| 이탈 | 인내심이 다해 손님이 떠나는 것 | |
| 버프 팩 | 상점에서 사서 3장 중 1장을 고르는 팩 | 카드깡, 카드팩 |
| 버프칸 | 버프를 보유하는 자리, 기본 5칸 | 버프 칸, 보유 칸 |
| 티어 | 메뉴 단계 t1~t6, 높을수록 비싸고 수요가 낮음 | 등급 |
| 가격대 | 티어 두 개 묶음, 일반 $, 고급 $$, 프리미엄 $$$ | 밴드 |
| 창고 퇴장 시간 | 창고를 닫을 때 깎이는 영업시간 | 트립 비용 |
| 후반 난이도 상승 | 달이 지날수록 인내심과 도착 간격이 줄어드는 것, 화면 문구는 손님 인내심 감소 | 램프 |

## 코어 재미

- 주문서, 재료, 조리 결과가 좁은 슬롯을 두고 경쟁, 자리가 사라지는 급박함
- 핵심 결정은 주문서를 더 받아 대비할지 그 칸을 재료로 쓸지, 재료를 얼마나 쟁일지
- 밀려오는 손님을 빠르게 쳐내는 정체 관리가 손맛

## 플레이 루프

1. 손님이 입구 큐에 줄, 그 순간부터 인내심 소모, 주문은 숨김
2. 손님 쪽지 클릭, 주문서가 빈 슬롯에 들어오며 공개, 손님은 줄에 유지
3. 창고에서 재료를 꺼내 슬롯에 배치
4. 도구 탭, 레시피 선택, 재료가 다 있으면 소비하며 자동 조리, 부족하면 비활성
5. 완성품 탭은 급한 손님에게 자동 서빙, 드래그는 지정 서빙, 서빙 시 점수와 자리 회복
6. 주문서를 더 받을지 재료를 더 놓을지 저울질

## 규칙 요약

| 요소 | 규칙 |
|---|---|
| 판 | 3x3 9칸 시작, 도구석 2에 일반 7, 한 칸씩 확장, 상한 21 |
| 도구 | 판 내 도구석 2칸에 고정, 구분 없이 둘 다 전체 메뉴 |
| 손님 큐 | 입구에 화면 최대 4명, 꽉 차면 화면 밖 대기, 빈자리 나면 즉시 입장, 넘쳐도 즉사 없음 |
| 인내심 | 2단계, 줄에서 주문 대기 타이머, 주문 받으면 음식 대기 타이머로 재시작, 만료 시 이탈 |
| 재료 | 창고에서 빈 슬롯으로만, 창고 퇴장 시간 탓에 한 번에 많이가 이득이나 슬롯 압박, 1개 1칸 겹침 불가 |
| 휴지통 | 안 쓰는 재료만 즉시 무료 폐기, 완성품과 주문서는 불가 |
| 완성품 | 도구 위에 남음, 빈 슬롯으로 옮겨 대기 재고 가능, 과잉 생산은 자리 리스크 |
| 서빙 | 탭은 가장 급한 매칭 손님 자동, 드래그는 특정 주문 지정 |
| 슬롯 순서 | 왼쪽 위가 첫 번째, 한 줄을 왼쪽에서 오른쪽으로 순회한 뒤 아래 줄로, 순서에 의존하는 효과는 이 순서로 적용 |

## 런 구조

시간은 주 단위로 쌓여 한 런을 이룬다.

| 단위 | 길이 |
|---|---|
| 1주 | 영업 한 번, 게임에서는 n주차 |
| 1개월 | 4주 |
| 1런 | 3개월, 12주 |

- 한 런 흐름은 주 영업, 주 마감 정산과 통과 판정, 상점, 다음 주 순
- 12주를 통과하면 런 완료
- 주 목표 미달이면 돈을 내고 통과, 최소 주 목표의 1/100을 내야 하고 낸 뒤 남는 돈은 최대 5원, 그만큼도 없으면 파산 신청으로 런 실패
  - 고정 비율이면 모아둔 돈으로 점수 목표를 쉽게 건너뛸 수 있어서, 돈으로 통과하는 대신 그만큼의 패널티를 남기려는 의도
- 런 도중 홈 버튼으로 런을 포기하고 타이틀로 갈 수 있다
- 처음 도넛 카페를 고르면 튜토리얼부터 시작한다
- 첫 런 완료 시 목숨 기능과 버거집이 해금, 목숨은 그다음 런부터 적용, 라멘은 준비 중
- 매주 마감에 누적 점수가 주 목표 이상이면 통과, 월 목표 440, 1680, 6600으로 크게 상승
- 월말 4주차는 제약 하나를 건 계약 갱신 심사, 아래 계약 갱신 심사 참고
- 후반 난이도 상승은 3개월차로 갈수록 선형, 인내심 20% 감소에 도착 간격 45% 감소
- 손님은 웨이브 없이 영업시간 내내 빈자리 나면 연속 등장, 월별 손님 수는 data/levels.gd
- 새 주 시작 시 소모품인 재료, 완성품, 주문서, 손님은 정리, 설비인 도구, 슬롯, 버프, 목숨은 유지

## 상점과 버프

- 상점은 슬롯 확장권, 랜덤 버프 팩 3장 택1, 보유 버프 관리로 구성, 버프는 판매 환급 가능
- 상품은 매번 3개, 슬롯 확장권이 남은 확장 수만큼 최대 2개 먼저 나오고 나머지는 버프 팩, 상품마다 한 번만 구매 가능
- 버프칸이 가득 차면 팩에서 카드를 고를 수 없고 보유 버프를 하나 팔아야 받을 수 있다
- 버프는 팩에서 뽑는 자동 적용 패시브, 점수 배수와 누적과 조건부 성장 같은 전략 축, 보유 상한 5, 욕심쟁이 버프로 하나 추가
- 목숨 전용 버프 4종은 여분의 심장, 휴식, 안전 배당, 무결점 보너스

## 가게

가게마다 코드는 공유하고 콘텐츠와 경제값의 대비로 성격을 다르게 한다.

### 구성

- 가게별 고유 재료/메뉴 세트, 창고에 뭉치게 배치
- 재료/메뉴 수: 도넛 8/6, 버거 6/4
- 가격 = 서빙 점수, t1~t6 = 1/2/6/8/12/20, 비쌀수록 수요 낮음, 가게별 조정 가능
- 메뉴 없는 가격대의 가격대 버프는 제외 예정, 버거는 가격대 2개라 t5/t6 버프 필터, 미구현 보류

가격대는 티어 두 개 묶음이고 가게가 가진 티어만큼만 운영한다. 게임에서는 $ 기호 개수로 표시한다.

| 가격대 | 티어 |
|---|---|
| 일반 $ | t1, t2 |
| 고급 $$ | t3, t4 |
| 프리미엄 $$$ | t5, t6 |

### 경제 파라미터

가게별 절대값이고 data/shops.gd의 econ에 둔다. 미지정 시 Config 기본 폴백.

| 필드 | 뜻 |
|---|---|
| patience_order | 큐 주문 대기 인내심, 초 |
| patience_dish | 슬롯 음식 대기 인내심, 초 |
| spawn_gap_min, spawn_gap_max | 도착 간격 최소/최대, 초, 사이 랜덤 |
| spawn_weights | 티어별 등장 가중 t1~t6, 합 100 |

- 기본 인내심/도착은 아래 숫자 표, 기본 수요 분포 30/22/18/15/10/5
- 영업시간, 후반 월배수 등 난이도 곡선은 가게 공용, Levels 소관
- 가게 성격 = 값들의 대비로 결정, 캡 없이 값으로 조절

## 계약 갱신 심사

가게를 세로로 깊게 확장하는 요소. 매 월말 4주차에 제약 1개를 건 채 한 주 영업을 완주해 그 달 목표를 넘겨야 한다. 게임 예고 문구로는 본사 감사라고 부른다. 코드에서는 boss라고 부른다. 제약 수치 value는 튜닝 전제.

### 등장 주기

매 월말 4주차마다 제약 1개가 발동한다.

- 제약은 월별로 랜덤 1개를 굴려 런 동안 고정, 예고가 곧 실제 보장
- 조회: `Boss.preview_for_month(month)`, `Boss.for_week(week_info)`는 is_month_end일 때만 반환

발동 경로

| 단계 | 호출 |
|---|---|
| 주 시작 | `session.start_day`가 `Boss.begin_day(wk)` 호출 |
| 분기 | `main._on_day_started`가 `Boss.is_active()`면 `_start_boss_intro`, 아니면 `_start_day_intro` |

디버그

| 수단 | 효과 |
|---|---|
| `Boss.queue_random()` | 다음 주 심사 예약 |

### 심사 판정

- 판정은 일반 주 목표와 같고 목표 값이 월 목표, 미달 시 처리도 런 구조와 동일
- `rent_skip` 버프 "한번은 봐준다"는 심사에도 유효
- 옛 "마감 보유 돈 이상 재계약비" 돈 기준은 폐기

### 심사일 제약

제약 5종. `scripts/boss.gd` POOL, value는 제약별 파라미터.

| type | 이름 `boss.<type>` | 아이콘 | value | 효과 | 배선 |
|---|---|---|---|---|---|
| small_kitchen | 좁은 주방 | boss_small_kitchen | 3 | 슬롯 3칸 잠금 | `locked_slots()`가 board로 |
| time_short | 단축 영업 | boss_time_short | 0.7 | 영업시간 ×0.7, 손님 수도 자연 감소 | `day_length_mult()`가 stats로 |
| pricey_trip | 비싼 발품 | boss_pricey_trip | 2.0 | 창고 퇴장 시간 ×2 | `warehouse_mult()` |
| slow_cook | 불 약한 화구 | boss_slow_cook | 1.4 | 조리시간 ×1.4 | `cook_mult()` |
| impatient | 인내심 바닥 | boss_impatient | 0.6 | 손님 인내심 ×0.6 | `patience_mult()` |

- 아이콘 이미지 `boss_<type>.png`가 `ICON_IMG`, 기본값 `boss_seal`

### 밸런스와 확장 후보

- value는 잠정, 시뮬과 실플레이로 튜닝
- 실플레이 로그상 3개월차 `impatient`의 목숨 압박이 약함
- 확장 후보는 확장아이디어.md

## 숫자

값은 모두 튜닝 전제. 상수 열은 코드 이름.

| 항목 | 값 | 상수 |
|---|---|---|
