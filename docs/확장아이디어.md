# 확장 아이디어

아직 구현하지 않은 확장 후보만 모은 설계 초안이다. 방향은 가게 수를 늘리기보다 버프 시너지를 깊게 만드는 쪽이다. 가격은 모두 현재 경제 스케일 기준 가안이다.

## 강화 레벨

버프를 키우는 축이다. 지금 버프는 레벨 없이 카드마다 고정값 하나를 가진다. 여기에 레벨 배수를 곱해 `효과값 = 기본값 × level_mult[Lv]`로 키운다. 예를 들어 조리 시간 30% 감소 카드가 Lv2에서 38%, Lv3에서 46% 감소가 되는 식이다.

### 방식

| 방식 | 시점 | 내용 |
|---|---|---|
| 버프 합성 | 런 중 | 같은 버프 2장을 Lv2 1장으로 합친다. 더 강해지면서 버프칸 1칸이 빈다 |
| 상점 강화권 | 런 중 | 상점에서 강화를 사서 보유 버프를 레벨업한다. 돈을 다른 상품과 나눠 써야 한다 |
| 메타 영구 강화 | 런 사이 | 런 후 자원으로 버프 기본값을 영구히 올려 다음 런부터 강해진다. 도감과 연결한다 |

- 합성은 보유 상한 다섯 칸과 직접 맞물려 공간을 벌면서 강해지는 이 게임만의 맛을 낸다.
- 추천 조합은 런 중 깊이를 주는 합성과 런 반복 동기를 주는 메타 강화다.

상점 강화권 상품 예시

| 이름 가안 | 효과 | 가격 가안 |
|---|---|---|
| 연마 | 보유 버프 하나를 골라 한 단계 강화 | 5 |
| 일괄 연마 | 보유 버프 전부를 조금씩 강화 | 12 |

- 강화가 강화를 부르며 급격히 세질 위험이 커서 등장 빈도와 가격으로 조절

### 구현 메모

- `Buffs._owned`가 지금 `Array[String]`이라 레벨을 담으려면 id와 레벨을 함께 가진 구조로 바꾼다.
- `Stats`와 `Buffs`의 값 계산에 `level_mult`를 곱하도록 배선한다.
- 합성 규칙은 같은 id 2장을 보유하면 합치고 버프칸 1칸을 비우며 최대 레벨을 정한다.

## 런 변주

런을 매번 다르게 만드는 축이다.

| 후보 | 범위 | 내용 |
|---|---|---|
| 주간 이벤트 | 런 내 | 대목, 불경기, 관리비 폭탄 같은 이벤트를 `Levels.MONTHS`의 주 데이터에 필드로 얹어 데이터로 정한다 |
| 심사 제약 추가 | 런 내 | 도구 하나 one_tool, 휴지통 폐쇄 no_trash, 막 구조 Act |
| 누적 난이도 | 런 반복 | 클리어할 때마다 누적 난이도를 해금해 월 목표를 올리거나 인내심이나 영업시간을 줄인다. 콘텐츠 추가 없이 수명을 늘리며 `Levels`에 난이도 레이어로 얹는다 |
| 메타 언락 | 런 반복 | 새 버프, 레시피, 도구를 등장 풀에 추가한다. 도감과 연결한다 |
| 시작 프리셋 | 런 반복 | 커피 특화, 넉넉한 슬롯, 많은 자금 같은 프리셋 선택. 후순위 |

## 버프 카드 후보

지금 없는 기능이 생겨야 성립하거나 효과를 다시 정의해야 하는 카드다. 성립하면 버프카드 문서로 옮긴다.

| 카드 | 남은 일 |
|---|---|
| 버프 팩 무료 리롤 +1회 | 리롤은 구현됐으니 카드만 추가하면 된다 |
| 휴지통에 완성품 버릴 때마다 +{n}원 | 완성품 버리기 기능이 필요하다 |
| 손님 쫓아내기 기회 | 쫓아내기 기능과 효과를 새로 정해야 한다 |
| 5명 단체 손님, 같은 메뉴 등장 확률 +{n}% | 단체 손님 개념을 새로 만들어야 한다 |
| 손님이 떠나면 바로 다음 손님 등장 | 현재 손님 등장 방식과 겹쳐 효과를 다시 정의해야 한다 |

## 상점 상품 후보

발라트로와 클로버핏을 참고했다. 버프칸 다섯 칸을 두고 경쟁하는 게 핵심 제약이라, 신규 상품은 버프칸을 쓰지 않으면서 파워나 유연성을 주는 레버를 가치 축으로 삼는다. 상시 강화권과 메뉴 레벨업이 그 축이다.

### 상시 강화권

발라트로의 바우처에 해당한다. 런 내내 유지되는 영구 패시브이고 버프칸을 쓰지 않는다. 비싸고 한 번만 살 수 있어 돈 쓸 곳을 다양하게 만든다.

| 이름 가안 | 효과 | 가격 가안 |
|---|---|---|
| 도매 계약 | 팩 개봉 시 카드 +1장, 후보확장 버프를 버프칸 없이 상시 적용 | 12 |
| 단골 리롤 | 리롤 기본 비용 50% 감소, 반올림 적용 | 8 |
| 임대 협상 | 슬롯 확장권 가격 표 전체 20% 할인 | 15 |
| 프랜차이즈 | 주 클리어 보상 매주 +5 | 20 |
| 큐레이션 | 팩에 T4 이상 고티어 카드 최소 1장 보장 | 14 |
| 시식 코너 | 매주 팩 하나 무료 개봉권 제공 | 18 |

- 런마다 서너 종만 등장, 전부 사면 재미 감소
- 등장 시점은 주차에 따라 증가

### 메뉴 레벨업 소모품

발라트로의 행성 카드, 클로버핏의 심볼 강화에 해당한다. 특정 메뉴의 기본 점수를 런 내내 영구히 올린다. 한 번 쓰면 사라지고 버프칸을 쓰지 않으며 티어 빌드를 깊게 만든다. 메뉴는 도넛 카페 기준이다.

| 이름 가안 | 효과 | 가격 가안 |
|---|---|---|
| 원두 로스팅 레벨업 | T1 커피 기본 점수 영구 +15% | 3 |
| 라떼 아트 레벨업 | T2 라떼 기본 점수 영구 +15% | 3 |
| 글레이즈 배합 레벨업 | T3 글레이즈드 기본 점수 영구 +18% | 4 |
| 가나슈 레벨업 | T4 초코도넛 기본 점수 영구 +18% | 4 |
| 마스카포네 레벨업 | T5 티라미수 기본 점수 영구 +22% | 5 |
| 다크초콜릿 레벨업 | T6 초코케이크 기본 점수 영구 +22% | 5 |
| 랜덤 레시피 노트 | 랜덤 메뉴 한 종 레벨 +1, 대신 저렴 | 2 |

- 같은 메뉴 중복 구매 시 레벨처럼 누적
- 가격 버프 mp, 판매 버프 sale, 수요 버프 dmd 계열과 곱연산 시너지
- 버프칸을 안 써서 강력, 등장 빈도와 가격으로 조절

### 일회성 소모품

클로버핏의 즉발 아이템에 해당한다. 버프칸을 쓰지 않고 한 번 즉시 발동해 위기 탈출이나 유연성을 준다.

| 이름 가안 | 효과 | 가격 가안 |
|---|---|---|
| 손님 호출 | 다음 주 첫 손님 등장을 앞당기거나 대기 손님 전원의 메뉴를 다시 뽑는다 | 3 |
| 가불 | 점수 일부를 나쁜 환율로 돈으로 변환 | 0 |
| 목표 유예 | 다음 주 목표 미달을 한 번 통과 처리, 한번은 봐준다 버프의 소모품 버전 | 8 |
| 폐기 처분 | 보유 버프 하나를 즉시 판매, 환급 30%로 상향 | 0 |
| 리롤 토큰 | 이번 방문의 팩 리롤 한 번 무료 | 2 |

## PC 확장

모바일 우선 후 나중에 PC로도 확장한다. 두 벌 제작이 아니라 로직, 데이터, 버프, i18n, UI 컴포넌트는 한 벌로 공유하고 레이아웃 배치와 입력 어댑터만 플랫폼별로 나누는 얇은 어댑터 층이다.

| 항목 | 내용 |
|---|---|
| 가로 레이아웃 | main.gd 조립부가 뷰포트 비율을 감지해 세로와 가로로 배치만 다르게 한다 |
| 스트레치 | project.godot stretch aspect를 keep에서 expand로. 급하면 세로 유지에 양옆 배경 프레이밍만으로도 대응 가능 |
| hover | PC는 mouse_entered로 툴팁과 강조, 모바일은 탭이나 롱프레스로 같은 정보 노출 |
| 입력 어댑터 | 커서, 탭 타깃 크기, 탭과 hover 트리거를 같은 함수로 모은다 |

- 착수 시점은 모바일 코어 재미와 버프 시너지 깊이가 검증된 뒤다.
- 지금부터 컴포넌트는 자기만 그리고 배치는 상위에서 하며, 상호작용은 함수 하나로 모은다. 통합 Move의 클릭과 드래그가 이미 그 기반이다.

## 추천 로드맵

1. 상시 강화권과 메뉴 레벨업. 버프칸을 안 쓰고 돈 쓸 곳을 늘리며 티어 빌드를 깊게 해 게임 정체성에 가장 맞다.
2. 버프 합성으로 런 내 깊이와 강화 레벨을 한 번에 넣는다.
3. 누적 난이도로 재도전성을 만든다. 구현 비용이 낮다.
4. 일회성 소모품으로 적은 비용에 유연성과 긴장 완화 레버를 더한다.
5. 메타 강화와 언락을 도감과 묶어 장기 동기로 삼는다.
6. 주간 이벤트는 심사 제약과 같은 방식으로 붙인다.
7. 상점 강화권은 밸런스 위험이 커서 나중에.
